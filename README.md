# Electronics Circuits

A collection of electronic circuit designs and simulations developed through hands-on experimentation and coursework.

The repository contains circuit designs created using different electronic design and simulation tools. Circuit files are provided in their native formats so they can be opened, inspected, and modified for further experimentation.




## Contents

### LTspice

Contains circuit schematics and simulations created using LTspice.

The `.asc` files can be opened directly in LTspice to inspect the circuit design and simulation setup.

### Logisim

Contains digital logic circuit designs created using Logisim.

### Future Additions

Additional circuit designs created using other EDA and simulation tools may be added as the repository develops.




## Current Tools

* LTspice
* Logisim
